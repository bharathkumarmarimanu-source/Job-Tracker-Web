What it does

Delete
Remove an application you no longer need.

Summary

How it is built

Object-oriented design

JobApplication is the base class. Referral and Online extend it, so the two kinds of application share one common structure. 

JobApplication
├── Referral
└── Online

Collections

A HashMap, keyed by application ID, makes it quick to find, update, or delete a single application. A HashSet keeps each company in the list only once.

Data is held in memory only, so the list resets when the program closes.
